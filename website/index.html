Edu 0.3

sha256: build on demand
  1. Verify the checksum: sha256sum VixzenOS-*.iso
  2. Write it: sudo dd if=VixzenOS-*.iso of=/dev/sdX bs=4M status=progress oflag=sync
  3. Reboot → boot menu → USB → try VixzenOS. Nothing installs unless you say so.

ISOs are built locally for now — press download to check for a local build.
